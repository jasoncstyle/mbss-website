Business platform plugin for Myrtle Beach Sailing School.

== Description ==

Student records, booking workflow, payments, scheduling, reporting, and CRM-lite lifecycle tracking.

All business logic lives here — separate from the MBSS Theme.

== Installation ==

1. Upload to wp-content/plugins/mbss-operations
2. Activate through the Plugins menu
3. Database tables are created on activation
