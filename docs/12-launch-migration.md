# Launch, Migration & Growth Roadmap

## Core Philosophy

Goal is **not** "launch a new website."

Goal is **launch a better business platform** without losing rankings, traffic, leads, bookings, or existing content.

MBSS already has rankings, traffic, bookings, and students. A bad launch destroys years of SEO equity.

## Migration Strategy

### Content Audit

Inventory every existing page. Categorize:

| Action | Meaning |
|--------|---------|
| Keep | Migrate as-is or with minor updates |
| Improve | Rewrite/upgrade (especially course pages, homepage, about, blog) |
| Merge | Combine redundant pages |
| Remove | Retire with 301 redirect |

### URL Preservation

| Scenario | Action |
|----------|--------|
| Page remains | Keep URL |
| Page moves | 301 redirect |
| Page removed | 301 redirect to nearest equivalent |

**Require:** Redirect spreadsheet (Old URL → New URL → Status)

### SEO Migration Checklist

Verify before launch:
- Meta titles & descriptions
- Schema markup
- Internal links
- Image alt text
- XML sitemap
- robots.txt
- Canonical tags

### Image Migration

Audit all images. Replace low quality, outdated, poor branding. Keep strong student/instruction photos and testimonials.

### Student Data Migration

**Recommendation:** Import existing student data if practical.

Preserve: profile, course history, contact info, notes.

### User Migration

Transfer: admins, instructors, captains, mates, office staff.

Require password reset workflow on first login.

## Soft Launch

**Duration:** 1–2 weeks before public launch.

**Purpose:** Catch issues, verify bookings, monitor analytics.
