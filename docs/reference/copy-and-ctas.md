# Copy & CTA Quick Reference

## Site-Wide CTAs (Only Three Primary)

| CTA | When to Use |
|-----|-------------|
| **Find Your Course** | Homepage hero, final CTA, course finder results |
| **Learn More** | Secondary exploration, course cards |
| **Reserve Your Spot** | All enrollment/booking actions |

**Rule:** One primary CTA per page.

---

## Words to Use / Avoid

| Use | Avoid |
|-----|-------|
| Liveaboard Certification Packages | Combo Courses, Course Bundles |
| Immersive Sailing Certification Packages | |
| Student Success Stories | Testimonials (as section label) |
| Reserve Your Spot | Register, Submit Form, Contact Us for Pricing |
| Starting at $XXX | Call for Pricing |
| Progression / Journey / Next Step | Course catalog framing |
