# Page Template Build Checklists

Use these checklists when building or reviewing each page type.

---

## Homepage (`/`)

- [ ] Hero: 80–100vh video loop, headline, dual CTAs, trust bar
- [ ] Interactive Course Finder (below hero) — mandatory
- [ ] Choose Your Path: 4 image cards
- [ ] Sailing Pathway graphic + CTA
- [ ] Featured Courses: 3 cards with "starting at" pricing
- [ ] Liveaboard section with flagship packages + private upgrade highlight
- [ ] Why MBSS: 5 differentiation cards
- [ ] Student Success Stories (video first)
- [ ] Meet Your Instructors
- [ ] Upcoming Courses: card layout with scarcity
- [ ] Online Certifications: 5 courses with price
- [ ] FAQ: 5–6 questions
- [ ] Final CTA
- [ ] Mobile section reorder implemented
- [ ] One primary CTA per viewport section
- [ ] Schema: Organization, LocalBusiness

---

## Course Page (ASA 101–114, 102, 106)

- [ ] Hero: student photo, outcome-first headline, quick facts, Book + View Dates
- [ ] Is This Right For You (first content section)
- [ ] What You'll Learn (cards)
- [ ] What You'll Be Able To Do (outcomes)
- [ ] Why Learn at MBSS (5 cards)
- [ ] Course Pathway with next-step CTA
- [ ] Course-specific reviews
- [ ] Upcoming dates on-page with scarcity
- [ ] Transparent pricing (price, deposit, balance)
- [ ] Course-specific FAQ (5+ questions)
- [ ] Final CTA
- [ ] Internal links to next course / package / book
- [ ] Schema: Course, FAQ, Review, Breadcrumb
